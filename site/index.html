谷歌 SEO 入门 从收录到排名 一步步做对

SEO 是 search engine optimization 的缩写，中文叫「搜索引擎优化」：有人在 Google 上搜一个词，你的页面能被找到、被点开，并且真的解决他的问题。拆开只有四件事——收录、关键词、排名、点击，这页按新手能上手的顺序，一件一件拆开讲。

自检

先花三分钟，查清楚你的站卡在哪一步

大部分「谷歌 SEO 没效果」，不是排得低，而是卡在前两步。三个问题，按顺序回答。

01

收录查了吗

页面没进库，后面所有优化都不存在。用 site: 抽 1% 看，或者直接看 Search Console 的覆盖率报告。

查法：site:你的域名 → 对比页面总数

02

有页面接得住这个词吗

很多站不是排不上去，是压根没有对应这类需求的落地页。先把你想要的关键词和现有页面一一配对。

查法：Search Console 查询报告 → 高曝光低点击

03

是排得低，还是没被召回

排名工具的「未找到」，可能是第 80 名，也可能根本没进候选池。这两种情况的解法完全相反。

查法：搜核心词，翻到第 8 页还没有，就是没进池子

工具

做谷歌 SEO，真正会用到的 8 个工具

工具不解决策略，但能省掉大量手工。这 8 个覆盖收录、关键词、竞品、技术排查四件事，都有免费额度。

Google Search Console

免费

唯一能告诉你谷歌抓了什么、收录了多少、哪些词带来曝光的地方。没有它，其它工具都是猜。

官方的搜索量和竞价数据，粗但权威。做词库的第一步，先在这里把每个词的量级摸清楚。

Ahrefs

付费

看竞品靠哪些页面吃自然流量、外链从哪来。比「它排第几」更重要的，是「它为什么排」。

Semrush

付费

和 Ahrefs 功能重叠，二选一即可。它的关键词难度和广告数据更细，做投放也用它。

Screaming Frog

免费版 500 URL

把一个站当爬虫爬一遍：标题重复、死链、重定向链、内链深度，一次全出来。

PageSpeed Insights

免费

用的就是谷歌自己的 Lighthouse，Core Web Vitals 的现场数据和实验室数据都在这里。

Google Trends

免费

判断一个需求是在涨还是在退。同一个词，两年前和现在的搜索量可能差十倍。

Bing Webmaster Tools

免费

顺手提交，成本为零。Bing 的抓取数据有时比谷歌更早暴露站点问题。

工具只负责给数据，判断还得自己做。这篇讲的就是怎么把数据读成结论。

选人

怎么挑一家靠谱的谷歌 SEO 公司

这行门槛低、话术多。下面六条建议你在签合同前逐条核对——其中三条，大部分公司过不了。

  1. 01
    报价和交付物写不写清楚

    只写「月度优化」「持续维护」的，等于什么都没承诺。交付物要能数得出来：几篇页面、几份文档、几次会。

  2. 02
    敢不敢给你看原始数据

    要 Search Console 的只读权限，而不是一张截图。截图可以挑，后台数据挑不了。

  3. 03
    承诺排名，还是承诺过程

    「一个月上首页」的直接走。排名不可控，过程和交付物可控——敢承诺过程的人，才是真干过活的人。

  4. 04
    内容是谁写的

    拿三篇他们写的页面出来看，不是案例封面。写不出来，就只能外包给按篇计费的人，质量随缘。

  5. 05
    技术问题谁改

    没有开发配合，诊断报告就是废纸。签之前问清楚：改代码的是谁，排期怎么走。

  6. 06
    不做了怎么退出

    合同里有没有交接条款。数据、账号、文档，到期之后归谁，要提前写明白。

FAQ

关于 SEO，常被问到的几个问题

SEO 和 SEM 有什么区别？

SEO 拿的是自然结果，不按点击付费；SEM 通常指竞价广告，点一次付一次钱。前者慢，但做起来之后不用再为每次点击买单；后者快，停投就停量。两者不是二选一——多数站先用广告验证需求，再用 SEO 把获客成本降下来。

收录、排名、点击，是什么关系？

四段接力：有页面覆盖这类需求 → 被收录 → 排到用户会点的位置 → 标题让人愿意点。任何一段是 0，结果就是 0。大部分「做了没效果」，卡在前面两段，而不是排名本身。

关键词密度还有用吗？

十年前就过时了。现在看的是语义结构和距离——词出现在哪里、离什么近。堆词只会让人读不下去，而「读不下去」本身就是个负向信号。

外链现在还重要吗？

重要，但「数量」早就不值钱了。被主题相关、没有利益关联的页面引用才有价值；同一个站、同一个 IP 段互相捧场，权重会被重新折算，等于白做。

新站一般多久能被收录、出排名？

收录看抓取预算和链接入口，快的一两天，慢的几周；排名更久，通常三个月起步。承诺「一个月上首页」的，要么在作弊，要么在骗你。

为什么同一个词，不同人搜出来的结果不一样？

结果里混了个性化信号：位置、语言、历史点击、设备。排名工具给的是某个固定条件下的快照，不完全等于你屏幕上看到的。看趋势，别盯单次截图。

谷歌官方文档里，最该先读哪几篇？

三篇：Search Essentials（收录与内容规范）、Search Console 的帮助文档（怎么看数据）、Core Web Vitals（体验指标）。中文互联网上流传的「SEO 技巧」，大部分正确而无用，少部分错误且有害。
