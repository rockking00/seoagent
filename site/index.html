自检

先花三分钟，查清楚你的站卡在哪一步

大部分「谷歌 SEO 没效果」，不是排得低，而是卡在前两步。三个问题，按顺序回答。

01

收录查了吗

页面没进库，后面所有优化都不存在。用 site: 抽 1% 看，或者直接看 Search Console 的覆盖率报告。

查法：site:你的域名 → 对比页面总数

02

有页面接得住这个词吗

很多站不是排不上去，是压根没有对应这类需求的落地页。先把你想要的关键词和现有页面一一配对。

查法：Search Console 查询报告 → 高曝光低点击

03

是排得低，还是没被召回

排名工具的「未找到」，可能是第 80 名，也可能根本没进候选池。这两种情况的解法完全相反。

查法：搜核心词，翻到第 8 页还没有，就是没进池子

做谷歌 SEO，真正会用到的 8 个工具

Google Search Console

免费

唯一能告诉你谷歌抓了什么、收录了多少、哪些词带来曝光的地方。没有它，其它工具都是猜。

Google 关键词规划师

免费

官方的搜索量和竞价数据，粗但权威。做词库的第一步，先在这里把每个词的量级摸清楚。

Ahrefs

付费

看竞品靠哪些页面吃自然流量、外链从哪来。比「它排第几」更重要的，是「它为什么排」。

Semrush

付费

和 Ahrefs 功能重叠，二选一即可。它的关键词难度和广告数据更细，做投放也用它。

Screaming Frog

免费版 500 URL

把一个站当爬虫爬一遍：标题重复、死链、重定向链、内链深度，一次全出来。

PageSpeed Insights

免费

用的就是谷歌自己的 Lighthouse，Core Web Vitals 的现场数据和实验室数据都在这里。

Google Trends

免费

判断一个需求是在涨还是在退。同一个词，两年前和现在的搜索量可能差十倍。

Bing Webmaster Tools

免费

顺手提交，成本为零。Bing 的抓取数据有时比谷歌更早暴露站点问题。

工具只负责给数据，判断还得自己做。这篇讲的就是怎么把数据读成结论。

选人

怎么挑一家靠谱的谷歌 SEO 公司

这行门槛低、话术多。下面六条建议你在签合同前逐条核对——其中三条，大部分公司过不了。

  1. 01
    报价和交付物写不写清楚

    只写「月度优化」「持续维护」的，等于什么都没承诺。交付物要能数得出来：几篇页面、几份文档、几次会。

  2. 02
    敢不敢给你看原始数据

    要 Search Console 的只读权限，而不是一张截图。截图可以挑，后台数据挑不了。

  3. 03
    承诺排名，还是承诺过程

    「一个月上首页」的直接走。排名不可控，过程和交付物可控——敢承诺过程的人，才是真干过活的人。

  4. 04
    内容是谁写的

    拿三篇他们写的页面出来看，不是案例封面。写不出来，就只能外包给按篇计费的人，质量随缘。

  5. 05
    技术问题谁改

    没有开发配合，诊断报告就是废纸。签之前问清楚：改代码的是谁，排期怎么走。

  6. 06
    不做了怎么退出

    合同里有没有交接条款。数据、账号、文档，到期之后归谁，要提前写明白。

这六条也是我给自己定的规矩。报价和交付物都写在页面上，签之前可以先对一遍。

FAQ

你大概会问的

多久能看到效果？

技术类问题通常 2–4 周就能看到索引和抓取的变化。内容和排名的增长一般 3 个月起，6 个月进入明显区间。任何承诺「一个月上首页」的，要么在作弊，要么在骗你。

和 SEO 公司、外包团队有什么区别？

公司卖的是人力和流程，我卖的是判断。你的项目由我一个人做策略和关键执行，不会转交给刚毕业的执行。代价是我同时只接 3 个，排期要等。

需要我这边配几个人？

最少需要一个能拍板的人和一个能改代码的人。内容可以由你的团队写（我给 brief 和改稿），也可以外包，但我不做纯代写。

只做 Google，还是也做百度？

以 Google 为主，百度可以做诊断但不接长期顾问。两边的规则、内容偏好和竞争结构差别很大，同时做通常两头都不深。
